## One finding that outlives the ruling

`reverie/src/timer.rs` documents, on the very constant 2733 consumes, that the
marker and counter exist for **retry classification** — *"detect-and-retry is the
correct mitigation, not a larger constant"*. But as built, 2733's refusal is a
plain `anyhow!`, so `classify_failure` reports
`HERMIT_INTERNAL_FAILURE class=cli-error` — the same bucket as a bad flag.

That is wrong under **either** answer to the owner's ruling: if refusing is
right, it must be identifiable so a harness can act on it; if labelling as known
flakiness is right, it must be distinguishable in order to be labelled.
`PolicyRefusal` already exists for the deliberate-refusal case. Worth fixing
regardless of which way the ruling goes.

## Method notes worth carrying, each one earned by an error I made

- **A mutation that reports a pass must first prove it was applied.** A harness
  of mine restored with `git checkout --` while the work was uncommitted, so the
  first restore reverted to `origin/main` and destroyed the tests; the next two
  mutations reported `0 passed; 0 failed` and read as clean. Commit a checkpoint
  first, and print `git diff` before believing a mutation result.
- **`0 passed; 0 failed` is not a pass**, and neither is a test that finishes in
  0.05s having taken an early-return skip. Both happened to me tonight.
- **A sha search cannot find a rebased copy and a patch-id sweep over `main`
  cannot find work sitting on a branch.** I asserted a commit was the only copy
  on exactly those two checks; it was already pushed and already had a pull
  request. Search all remote refs by patch-id, or by subject line, which survives
  a rebase.
- **A file-overlap check misses a moved dependency pin.** On 2733's rebase, three
  crossed commits touched neither reviewed file, but one moved the Reverie pin —
  and the change depends on three Reverie symbols. Diff the pinned files, not
  just the reviewed ones.
- **Check a git-dir path is absolute before concluding "no in-progress state".**
  My first such check resolved against the wrong directory and reported clean.
