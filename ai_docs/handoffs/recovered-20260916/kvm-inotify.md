- Socket-right insertion now walks the complete component in both directions,
  including existing receiver descendants and child fan-in. It admits no more
  than 4096 distinct socket descriptions, 4096 live strong edges, 8192
  adjacency inspections, or 64 strong edges on one path. Traversal charges
  edges incrementally without first cloning an unbounded neighbor list. A
  refusal returns `EOPNOTSUPP` before the host send and leaves both the kernel
  peer queue and the existing modeled graph unchanged.
- `sendto` and `sendmsg` distinguish the connected peer from an explicit
  destination. A successful `connect` clears the old modeled peer. Ordinary
  sends to explicit or retargeted destinations reach the host without adding
  a marker to the old peer; a socket or inotify descriptor transfer whose
  destination cannot be represented returns `EOPNOTSUPP` before the host
  send. Regular descriptor passing on a sending socket without KVM description
  state remains supported.
- Anonymous socketpair message publication and receipt share one lock. Host
  send and receive calls under that lock are forced nonblocking. Before the
  first datagram marker is admitted, a zero-time poll through a temporary

  `EOPNOTSUPP` before a modeled host send and cannot consume the next marker

- The ordering boundary is valid for production socketpairs because their host
  endpoints are private to `LoadedStaticElf`: guest `dup`, fork, and received
