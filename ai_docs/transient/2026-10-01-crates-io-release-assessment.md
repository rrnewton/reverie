# crates.io release assessment for Hermit and Reverie (2026-10-01)

Requested by the owner on 2026-10-01: "Which have we actually released to crates.io? Produce an assessment of what it would take for us to do a release ~today."
Prepared by a coord2 research subagent. Repositories were read at origin/main: hermit 01341d666, reverie dbf2b5c88. Nothing was published and nothing in the repositories was changed. Scratch evidence is on devbig030 under /var/tmp/crates-assess/.

## What is on crates.io

No real Hermit or Reverie code has been published.
- 26 empty `0.0.1` name reservations were published on 2026-07-31 between 16:21Z and 19:34Z, plus `hermit-detcore` on 2026-08-07. They came from `crates-squat-staging/`.
- The only real code published is `liteinst2`: 0.0.1, then 0.1.0 at 20:58Z on 2026-07-31.
- Owners and download counts were not read: the crates.io API returned 403 at the proxy. Versions and dates come from the sparse index (index.crates.io).

Names held by unrelated projects: `hermit` (hermit-os unikernel, 0.13.0), `reverie`, `reverie-util`, `detcore`, `syscalls`, `nostd-print`, `edit-distance`. `fbinit` 0.2.0 is Facebook's rust-shed and can be used as-is.

## Blockers

- **reverie-liteinst:** it fails to build against the published `liteinst2` 0.1.0, because it needs git rev 2032b49. Publish `liteinst2` 0.1.1 first.
- **Renames:**
  - `reverie-util` to `reverie-utils`.
  - `experimental/nostd-print` gets a new name, or `publish = false`.
  - The CLI package `hermit` (hermit-cli/Cargo.toml:4) becomes `hermit-run`; the binary stays `hermit`.
- **Hermit dependencies crates.io rejects:**
  - 21 git dependencies on reverie across 8 manifests, 9 of them in publishable crates (detcore/Cargo.toml:75,88; detcore-model:20; hermit-cli:58-63).
  - hermit-cli:46 depends on the unpublishable `hermit-test-workdir`.
  - The optional `detcore-dbt` dependency (hermit-cli:39).
  - Versioned dev-dependencies at detcore:84,89; drop the `version`.
  - `fbinit` comes from a git branch; use `0.2.0`.
- **Nightly only:** reverie-ptrace/src/lib.rs:31 uses `#![feature(internal_output_capture)]`. crates.io accepts nightly-only crates.
- **Size:** every crate is under the 10 MB limit; the largest is reverie-dbt at 5.0 MiB compressed. The dbt, e9patch and sabre crates build their vendored code with cmake/make; those builds were not verified, and e9patch and SaBRe carry GPL licenses.
- **LiteInst under `cargo install`:** an installed hermit has no `libreverie_liteinst.so` (lookup at hermit-cli/src/lib.rs:956), so it gets ptrace and kvm only.
- **Housekeeping:**
  - No crate directory has its own LICENSE file.
  - `repository` points at facebookexperimental.
  - The manifests are `@generated by autocargo`, so an fbsource sync may overwrite hand edits.

## Minimum viable release (ptrace, kvm and liteinst; no dbt, sabre or e9patch)

Publish order (~17 uploads):
1. `liteinst2` 0.1.1.
2. Reverie: reverie-memory, reverie-process, safeptrace, reverie-syscalls, reverie-core, reverie-rpc-transport, reverie-preload, reverie-ptrace, reverie-kvm, reverie-liteinst.
3. Hermit: hermit-resources, hermit-test-workdir, detcore-model, hermit-detcore, hermit-verify, hermit-run.

Effort is about 5–7 hours of agent work:
- about 1 h of edits;
- 2 PRs, each with an exact-head validation and landing, about 3–4 h;
- about 0.5 h to publish;
- about 1 h for a `cargo install hermit-run` smoke test.

Owner decisions:
1. Authorize the irreversible publish.
2. Confirm which account owns the reserved names.
3. Decide whether Meta-copyright facebookexperimental code may be published under that account, and which `repository` URL to use.
4. Choose the CLI package name: `hermit-run` or `hermit-cli`.
