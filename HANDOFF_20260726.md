## Objective

Implement `Guest::has_cpuid_interception` for the DBI backend and wire native
CPUID emulation through to the Rust `Tool::handle_cpuid_event`. Today the native
client (`native/client.c`) already traps EVERY guest `CPUID` (via
`rewrite_cpuid` app2app + `emulate_cpuid` clean call) and answers from hardcoded
`deterministic_cpuid` tables, but it NEVER calls Rust, and
`has_cpuid_interception()` returns the trait default `false`. This ratchet
surfaces CPUID to a subscribing Tool, matching the ptrace backend's contract.

## Chosen design (contained, additive, prototype-runtime-gated)

Mirror the round-16 pattern (env-var test tool + ActiveTool enum + dispatch()
+ C fixture + shell E2E + unit tests). Hard-extern `reverie_dbi_runtime_cpuid`
gated on `feature="prototype-runtime"` exactly like the other runtime callbacks.

### 1. `reverie-dbi/src/lib.rs`
- Add `use reverie::CpuIdResult;` (re-export of `raw_cpuid::CpuIdResult`,
  fields `{eax,ebx,ecx,edx}: u32`).
- Add Guest impl override (after `backtrace`, before closing `}`):
  ```rust
  // AUTONOMOUS-BOT-IMPLEMENTED
  // TODO-HUMAN-REVIEW(PR-ratchet17)
  fn has_cpuid_interception(&self) -> bool {
      cfg!(target_arch = "x86_64") && T::subscriptions(self.config).has_cpuid()
  }
  ```
  Honest semantics: interception is real exactly when the tool subscribed CPUID
  AND on x86-64. Non-subscribing tools still get the deterministic native table,
  but their handler is never called, so `false` is honest for them.
- Add `run_tool_cpuid<T>(...) -> Option<CpuIdResult>` (x86_64-gated), modeled on

  `!T::subscriptions(config).has_cpuid()`, then
  `run_ready(tool.handle_cpuid_event(&mut guest, eax, ecx), &tail_result)`
  mapping `Some(Ok(r)) => Some(r)`, `Some(Err(_)) | None => None`.
- Add extern (model on `reverie_dbi_runtime_pre_syscall` ~line 1370):
  ```rust

  pub unsafe extern "C" fn reverie_dbi_runtime_cpuid(
      context: *mut c_void, tid: i32, pid: i32, branches: u64,
      eax: u32, ecx: u32, out: *mut u32,
      invoke_syscall: SyscallInvoker, read_registers: RegisterReader,
      write_registers: RegisterWriter,

  ```
