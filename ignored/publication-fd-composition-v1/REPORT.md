This is an isolated, unexecuted source composition of the inactive publisher frozen-v1 and descriptor-entry repair final-v3, both based on Reverie 000c15a1161ea2d58749431b5ddaaa97f7aa37d5. It is author preparation for independent review, not composition approval. The live publisher, HEAD/index, prior packets, caches and released leases were not changed.

The complete candidate is `source/` (2,621 manifest entries, with seven symlinks and three unexpanded gitlinks). `SOURCE.patch` contains all three product paths, including the complete private publication module. `PUBLISHER-TO-COMPOSED.patch` and `FD-TO-COMPOSED.patch` expose both directions. The original ignored Cargo.lock is retained byte-identically and bound separately. `INPUTS-INITIAL.json`, `SOURCE_INPUTS.json` and the final readback bind the immutable component packets and every proposed source entry.

The composition preserves the publisher's deferred destruction while importing the FD repair. `LoadedStaticElf::insert_file` now returns the replaced File instead of dropping it internally. `duplicate_fd` keeps the publisher's explicit transaction-release-before-drop sequence; `duplicate_fd_at_or_above` uses the same explicit handoff. Close removes the entry marker while retaining the File until after unlock. Exec keeps the publisher's retired-file vector, stdin handling and retired-table handoff, while filtering FD markers to the surviving entries. Exit clears only the retiring executor's markers and retains the existing File/stdin drop ordering and surviving sibling table. Four textual conflicts and the nonconflicting helper adaptations are documented in `CONFLICTS.md`.

All tests are unchanged. The entire executor tests module equals FD final-v3 byte-for-byte; the entire publisher module, including all seven new tests, equals publisher frozen-v1. Every other source entry equals the publisher snapshot. The proposed selection is the union of the existing 59 publisher and 15 FD selectors, with their one identical exec selector counted once: 73 declarations (64 lib and nine static VM declarations). No source inventory count is inferred from that selection. The candidate has not been formatted, compiled, listed or tested.

`PLAN.md` and `qualification-proposal/` propose fresh source/artifact qualification. The only material caller changes from the qualified publisher caller are the already-qualified FD timeout-executable binding and isolated-snapshot afterfile guard; lib plus static compilation, parser, observer, lease protocol and resource limits remain unchanged. The caller proposal is not deployed and does not launch work.

The earlier evidence remains component evidence. Publisher's 59 passing selectors and FD's 15 passing selectors are not a pass on this composition. The publisher's first raw-0 warning refusal, FD's first format failure, and the original same-inode baseline raw-101 assertion remain unchanged in their original packets. No assertion, tolerance, comparator, skip, expected error, or failure label was weakened. No public API, publication caller, selector permit, timer/wait activation, FIFO support or descriptor-width change is added.

A concrete pre-activation limitation remains: publication uses authoritative FileTableState carriers, while `refresh_signalfd_readiness_for_signal_locked` uses an executor's installed `state.files`. Entry markers only repair synchronization when `install` runs; they do not refresh a stale executor outside execute. `CONFLICTS.md` records the source path and required focused follow-up. This candidate deliberately does not repair or claim to discharge that limitation. The current private failure latch and actual lock ordering are also unchanged; this composition does not add owner terminal notification.
