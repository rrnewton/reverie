This is an author clarification to the frozen timer integration design v2, not independent approval. The original REPORT.md and INTERFACES.md remain unchanged. It incorporates the actual Claude v2 findings (82f4746be093064cdcd751b539c4f8cab738c56e8247d5bf67e531a1e1ce1430) and root's source check.

- Hermit must preserve normal KVM ChildExit scheduler bookkeeping, child completion and fork/exit success while structurally excluding the host signal-send branch at both due-event sites. Reaching ChildExit is not by itself a terminal unsupported state. The Reverie child-exit receiver primitive exists; current Detcore does not call it in its production scheduler, so its existence does not establish guest SIGCHLD delivery. The previous text must not be read as authority to remove ChildExit behavior or infer absent receiver machinery.
- Process retirement must remove the dedicated KVM real-timer heap entry and seal the process registry. Retained committed dequeue acknowledgments remain bound to the retired lifetime and cannot rearm it or target a reused PID. Hermit records the startup-admitted identity for cleanup; a backend getter that returns None after retirement does not erase a committed SignalDequeue.process.
- A typed control received by an RPC helper that does not support controls is terminal protocol failure. It is neither an ordinary grant nor an unreachable panic.
- Reverie selects journal observation through Tool::observe_signal_dequeues(config), default false, before the initial thread-start callback. This realizes startup-selected policy without changing other Tools. Admission identity is stamped from the executor's original task/process generations; all three consumers validate that stamp under lifecycle -> process -> thread locks before removing an event. Fork/clone require fresh thread admission; exec retains the same process removal sequence.
- For an opted-in Tool, process alarm publication additionally requires the current original syscall callback's unconsumed capable site. A prepared caught/fatal reservation consumes that eligibility. Other existing primitive contexts remain available to unopted Tools. Returning ordinary injections remain available inside observation and caught posthooks; process-changing and tail handoffs are refused before effects while that ownership must be retained. This is a nested-observation restriction, not a claim that every ordinary KVM injection is refused.

The historical host victim remains unknown. Structural exclusion of host signal delivery is a required property of the Hermit implementation, not measured attribution for that historical event. This Reverie component has no timer heap, phase arithmetic, scheduler wait ownership, continuous-time trajectory change, INFO/replay policy change, or setitimer parity result. Hermit's implementation and the combined executable paths still require their own review and qualification.
