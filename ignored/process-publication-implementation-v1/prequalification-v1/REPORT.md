This is the first concrete inactive implementation, based on Reverie 000c15a1161ea2d58749431b5ddaaa97f7aa37d5. It is uncompiled, unformatted, unexecuted and not independently approved. The complete patch includes the new untracked product module; no index, refs or frozen earlier evidence changed.

Three product paths: executor.rs and elf.rs integrate registration, current-image replacement and shared transaction participation; process_signal_publication.rs contains the private registry, publication entry points and seven new unit declarations. The registry contains weak process bindings; each executor owns its process binding and shares the run registry. Threads share binding/transaction, fork creates a fresh process binding with exact parent identity, and exec replaces weak image/file bindings under file-table plus transaction ownership. Image revisions use allocation identities rather than a wrapping integer. Every publication revalidates the revision and exact live process generation after acquiring locks. Last-task retirement makes publication stale even while its executor exists; retaining the weak control after all executors drop keeps no process, file or G alive.

No GlobalTool hook, public API, ToolControlled mode, selector, wake callback, scheduler/child caller, due-site admission, wait behavior or sibling limit changes. Old callback publications retain their existing validations and result semantics. The new methods have no production call site. Exactly three item-level `cfg_attr(not(test), expect(dead_code, reason = ...))` annotations state that control creation and the two private publication entry points are intentionally inactive. All bodies compile in production; tests use them. No crate lint setting or -D warnings gate is changed.

The transaction spans pending changes and readiness writes for existing callback publication, deferred/kill delivery, three consumers, ignored-disposition flushing, signalfd mask/create/dup/close, mask/frame restoration, fork/exec and task retirement. Locked helper variants avoid recursive mutex acquisition. The publisher locks the authoritative FileTableState before the process transaction, then validates lifecycle and signal state; it never uses an arbitrary callback's local descriptor snapshot. Ordinary read/write, blocking waits and Tool hooks do not acquire this transaction. Descriptor duplication/close and exec descriptor cleanup remain existing metadata operations; no imported-FIFO or cancellable-host-I/O guarantee is added.

Publication returns queued/coalesced/suppressed receipts with target, current image, pending generation and disposition. It does not return a publisher mask as receiver eligibility. Before-effect refusal leaves pending untouched. Actual readiness failure after insertion retains the exact receipt and first errno in a run-local latch and refuses later private publication. It does not roll back, dequeue, notify G, resume instructions, or itself terminate the driver. Future owner terminal transition/notification is explicitly absent and required before activation; this private latch is not advertised as whole-run supervision.

The private normal-child input has no production constructor. It binds exact parent/child generations, verifies the registered parent and actual lifecycle exit status, and encodes supplied UID/CPU fields without inventing values. Tests supply explicit fixture accounting. A future child completion rendezvous must authenticate those accounting fields, retain the owned child until publication and implement waitability/staging/ack separately. The current ChildCompletion numeric/status route is not silently promoted to that authority. Killed/core/orphan cases are not newly claimed.

Seven new declarations exercise masks/dispositions/coalescence, invalid payload and reused/closed identity, leader retirement with a surviving thread and exec rebinding, aliases/all three dequeue routes/ignore flushing, real preflight versus post-insertion readiness failure, concurrent enqueue/dequeue readiness consistency, and parent/generation/status-checked normal child publication. Error injection deliberately substitutes a read-only carrier in the authoritative table; it is a corruption control, not a claimed normal production operation. The concurrency control permits either linearization order and requires pending/readiness/result agreement; it does not claim deterministic receiver selection. Existing admission/journal/frame controls are retained unchanged.
