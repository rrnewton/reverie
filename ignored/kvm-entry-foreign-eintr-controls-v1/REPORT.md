The control constructs a real 16 MiB backend, installs the two-byte real-mode busy loop, and calls the actual public `KvmBackend::run` on an owned host worker. The existing before-run hook announces the actual `pthread_t` and arms existing counters. The controller waits until the untracked RUN dispatch counter has incremented after mask installation, then repeatedly sends real SIGURG until it obtains the actual result. A signal may still precede kernel entry; only the required direct `Error::Kvm` with `errno == EINTR`, exactly one RUN, zero recorded exits and no syscall-handler invocation establishes the intended result. No exact signal count or timing inference is claimed.

A mutex-protected target lease remains owned by the live host worker. Each sender holds that mutex through `pthread_kill`; withdrawal happens on the worker before it can exit. After sending its backend/result, the worker waits for a bounded release message. The controller permanently stops sending before release and physical join. Thus even an expired release wait cannot authorize a send to a retired/reused pthread. The worker changes only its own mask, verifies SIGURG is unblocked, checks that entry restored its selected caller mask, then restores and verifies the entire saved libc signal-mask representation before join completes. Other blockable signals are excluded from this fixture; no claim is made to control libc-reserved signals.

The test requires no gate failure and no clock interval. It then installs a finite HLT program on the same returned backend and invokes the public loop again, requiring success, one additional RUN/mask installation, exactly one HLT exit, unchanged caller mask and no worker handles. These checks cover fresh admission after the foreign interruption.

Both controller handshakes and the send loop use five-second deadlines, with yielding and no sleep as ordering evidence. An owning cleanup guard retains the actual host thread on every early assertion failure. Failure-only rescue requests the real reserved-signal gate close and poisons admission, releases the worker and joins it. Rescue is never accepted as a foreign EINTR success. Individual blocking KVM operations and physical join still rely on the coordinator's outer finite runner; the deliberately busy guest has no internal instruction-count bound.
