This is an uncompiled native Linux reference probe for the timestamp candidate. It is not a Hermit guest or a parity test. Each invocation runs one case in its own process. It does not change PR_SET_TSC, start a perf counter, use ptrace or run a VM.

Planned selectors are `positive rdtsc 0..15` and `positive rdtscp 0..15`, plus each of `lock`, `overlength`, `step`, `edge`, and `rf` for both instructions with prefix index 0: 42 native cases. Missing native RDTSCP is exit 77 and explicitly unexecuted, never success. Positive checks use architectural properties, not a fixed timestamp value. The page edge cases distinguish a completed two-byte RDTSC followed by a debug trap from RDTSCP fetching its third byte on a nonexecutable page. The RF case requests RF and TF through an actual signal return at the timestamp instruction, then checks the retirement trap. It observes the requested context and the flags after retirement; it does not independently sample whether the kernel restored RF before the timestamp.

The source must be reviewed and compiled with strict warnings through a concretely bounded caller. Source, compiler, ELF and loader inputs must be bound before running. Reuse the existing finite per-selector resource limits; no execution is authorized by this file. Any mismatch is retained as evidence and investigated before changing either the probe or the backend expectation.

V2 preserves all V1 checks and adds raw register/flags/stack diagnostics. The snapshot uses static storage so those diagnostics remain defined after siglongjmp. The V1 source and its review remain retained. Neither version has been compiled or run.
